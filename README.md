## ✨ Features

- **Candidate Exam Engine:**
  - Timer countdown clock with visual notifications.
  - Question palette navigation (Current, Answered, Marked for Review, Unanswered).
  - Multiple question formats (MCQ, True/False, Short Answer, Essay).
  - Security controls: Tab-switch violation alerts, right-click & copy protection, refresh state persistence.
- **Instant Result & Review:**
  - Immediate percentage score calculation & Pass/Fail status.
  - Question-by-question breakdown with answer key comparisons & explanations.
  - One-click print/PDF export support.
- **Admin Panel:**
  - Dashboard analytics (Students, Exams, Questions, System Average Score).
  - Question Bank CRUD (Add, Edit, Delete, Search, Filter by Subject/Difficulty).
  - Create & Manage Exams (Set duration, passing %, randomize questions).
  - Student Directory & Results Monitoring.

## 🛠️ Technology Stack

- **Storage:** Browser `localStorage` engine for demo state and session management.
